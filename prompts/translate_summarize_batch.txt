다음 기사 데이터의 title과 description을 한국어로 번역하세요.
description은 RSS 설명의 일부일 수 있습니다. 생략된 내용을 추측하거나 요약하지 마세요.
source는 번역 문맥이며 출력하지 않습니다. 코드 분석과 분류는 하지 마세요.

기사 데이터:
{articles_json}

출력 형식:
{{"articles": [{{"article_index": 0, "translated_title": "번역 제목", "translated_description": "번역 설명"}}]}}

- 각 입력 index를 article_index로 그대로 반환하세요. 입력마다 정확히 한 개의 결과가 필요합니다.
- 제목은 빈 문자열이나 null일 수 없습니다.
- 설명이 비어 있으면 translated_description은 빈 문자열로 유지하세요. 그 외에는 빠짐없이 번역하세요.
- 기술 용어와 코드 식별자는 시스템 규칙을 따르세요.
- 다른 필드나 Markdown 코드블록 없이 JSON 객체만 반환하세요.
